Due to enhanced security measures for Drupal 7 websites, authentication for these features and access to secure content is currently only available via UQ Wi-Fi or the UQ VPN. Update Using the VPN is straightforward, and instructions for installing and using it are available on My.UQ: https://my.uq.edu.au/information-and-services/information-technology/working-remotely/vpn-virtual-private-network Information about these changes has been sent to all Drupal Editors and Publishers via the Web Content Community channel and email. If you have not received it, please check your junk or spam folder.
